# Fixitium
A simple, responsive bilingual (FI + RU) service website for offering basic computer repair and IT support. Includes service listings, pricing, and a clean layout suitable for a small business or portfolio project.

Modern bilingual service website (Finnish + Russian) for a small IT support business.
The site presents computer repair and maintenance services such as dust cleaning, virus removal, software installation, system optimization, diagnostics, and PC assembly.
Built as a clean, responsive, professional landing page with a focus on clarity, usability, and simple service presentation.

Features:

Responsive layout (mobile‑first)

Two languages: Finnish & Russian

Dynamic language switcher

Service cards with clear descriptions

Pricing section

Contact form (frontend only)

Clean structure for easy future expansion

Suitable both as a real small business website and as a portfolio project
